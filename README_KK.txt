4D BOOK — жариялауға дайын бастапқы сайт

Құрылымы:
- index.html — басты бет
- 1-toksan.html — I тоқсан материалы
- 2-toksan.html — II тоқсан материалы
- 3-toksan.html — III тоқсан материалы
- 4-toksan.html — IV тоқсан материалы

Жергілікті тексеру:
1. ZIP архивін ашыңыз.
2. index.html файлын браузерде ашыңыз.
3. Басты беттегі тоқсан сілтемелерін тексеріңіз.

Интернетке жариялау:
- Бұл — статикалық HTML сайт. GitHub Pages, Netlify немесе Cloudflare Pages сияқты хостингке осы буманың ішіндегі барлық файлды бірге жүктеңіз.
- Басты бет ретінде index.html автоматаар нээгдэнэ / index.html негізгі бет болып ашылады.
- Төрт тоқсан файлын жеке-жеке емес, бір бумада бірге сақтаңыз.

Маңызды шектеу:
Бұл жинақта ашық сайттың басты беті және берілген төрт HTML оқу материалы бар. Оқушы/мұғалім аккаунттары, серверлік дерекқор, ортақ үлгерім журналы және әкімші панелі әзірге іске қосылмаған. Оларды қосу үшін бөлек backend, авторизация және дерекқор қажет.
